This is a fork and Chinese translation of project [A Gentle Introduction to the Art of Mathematics](http://osj1961.github.io/giam/)
====
The original project is a fantastic book to learn mathematical proofing and the foundations of mathematics. 

For convenience, I used XeLaTeX for this CJK project and separated the Chinese version code into different files or directories.

Of course, LLMs have done the most work, and it went well. I've browsed this translation and corrected the obvious mistranslations.

I'm teaching my kid with this book to learn how to think about math or anything rigorously. I'm putting the proofreading work into the preparation of each teaching. Of course, this is a slow process, and I may jump over some sections, so please feel free to submit issues.
